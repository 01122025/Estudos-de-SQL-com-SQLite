# 🚀 Projeto de API de Agendamentos

Projeto pessoal desenvolvido paralelamente aos meus estudos de SQL.

A ideia deste projeto é aplicar na prática os conhecimentos adquiridos durante o curso **"SQLite Online: conhecendo instruções SQL"**, utilizando esses conceitos como base para a construção de uma API conectada a um banco de dados.

## 📚 O que estou praticando

* Criação de tabelas
* Definição de tipos de dados
* Chaves primárias
* Relacionamento entre tabelas
* Inserção e consulta de dados
* Organização de uma estrutura de banco de dados
* Integração do banco de dados com uma API

## 🗄️ Estrutura inicial

O banco de dados possui tabelas relacionadas a:

* Usuários
* Clientes
* Profissionais
* Serviços
* Estabelecimentos
* Endereços
* Agendamentos

## 🚧 Status

**Em desenvolvimento.**

A estrutura atual representa uma primeira versão do banco de dados e ainda passará por ajustes, principalmente na definição dos relacionamentos, chaves estrangeiras, tipos de dados e regras de negócio.

## 🎯 Objetivo

Utilizar este projeto como forma de colocar em prática os conhecimentos adquiridos durante meus estudos de SQL e acompanhar minha evolução no desenvolvimento de aplicações conectadas a bancos de dados.
