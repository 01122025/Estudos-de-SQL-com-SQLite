# 📚 Estudos de SQL com SQLite

Olá! 👋

Este repositório reúne os exercícios e práticas que desenvolvi durante o curso **"SQLite online: conhecendo instruções SQL"**, realizado na **Alura**.

Este foi um dos meus primeiros passos no aprendizado de SQL e, ao longo do curso, pude conhecer os fundamentos da linguagem e praticar a criação e manipulação de bancos de dados utilizando o **SQLite**.

## 🎯 O que aprendi

Durante o curso, aprendi conceitos importantes de SQL, como:

* 📌 Conhecimentos básicos sobre a origem e utilização da linguagem SQL
* 🗄️ Criação de tabelas
* ✏️ Alteração de tabelas
* 🗑️ Exclusão de tabelas
* ➕ Inserção de dados
* 🔎 Consultas utilizando `SELECT`
* 🎯 Aplicação de filtros nas consultas
* 💻 Utilização do **SQLite Online** para praticar SQL

## 🛠️ Tecnologias utilizadas

* **SQL**
* **SQLite**
* **SQLite Online**
